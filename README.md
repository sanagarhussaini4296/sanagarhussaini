# پیغامِ ہدایت (Paigham-e-Hidayat)
### باضابطہ ویب پورٹل برائے کلام و شاعری، مقالات و مضامین اور کتب خانہ

**پیغامِ ہدایت** اردو اور سندھی عزائیہ، عقیدتی اور فکری ادب کا ایک باوقار ڈیجیٹل پلیٹ فارم ہے۔ اس میں نوحہ جات، مناقب، مراثی، سلام، فکری مقالات اور نایاب کتب کو خوبصورت **جمیل نوری نستعلیق** اور **ایم بی لطیفی** خطوط میں پیش کیا گیا ہے۔

---

## اہم خصوصیات (Key Features)

- 📜 **دیوانِ کلام و شاعری**: اصنافِ سخن (حمد، نعت، قصیدہ، منقبت، نوحہ، سلام، مرثیہ) اور مناسبات (محرم و شہادت، ولادت و اعیاد) کے مطابق فلٹرنگ۔
- 🎙️ **اسٹیج و منبر ریڈنگ موڈ (Mimbar Mode)**: منبر پر پڑھنے کے لیے فل اسکرین، آٹو اسکرول، پرنٹ شیٹ اور فونٹ سائز کنٹرول۔
- 📺 **یوٹیوب ہم آہنگی (Direct YouTube Integration)**: ہر کلام کے ساتھ براہ راست یوٹیوب ریکارڈنگ لنک۔
- 🎨 **تصویری کارڈ جنریٹر (Social Media Quote Card)**: واٹس ایپ اسٹیٹس اور فیس بک کے لیے ہائی ریزولوشن امیج کارڈ ڈاؤنلوڈ۔
- ✍️ **مقالات و تحقیقی مضامین**: تفصیلی فکری اور ادبی جائزے تخمینہ وقتِ مطالعہ کے ساتھ۔
- 📚 **کتب خانہ و مطالعہ گاہ**: پی ڈی ایف کتب کے مفت ڈاؤنلوڈز اور معتبر علمی ویب سائٹس کے مآخذ۔
- 🔤 **خطوط کی تنصیب (Fonts)**: جمیل نوری نستعلیق (اردو)، ایم بی لطیفی (سندھی)، اور ایم بی امر فیاض۔

---

## چلانے کا طریقہ (Getting Started)

```bash
# 1. پیکیجز انسٹال کریں
npm install

# 2. لوکل سرور چلائیں
npm run dev

# 3. پروڈکشن بلڈ تیار کریں
npm run build
```
